      How it stays fast
      
      
        
        
      • One runQuery References call per module — no element is read.
        • 
        
      • Cached answers cost nothing; open modules are queried before closed ones.
        • 
        
      • A module it opens is closed right after its query, so Studio stays small.
        • 
        
      • Platform / Forge modules ((System), OutSystemsUI…) are listed, never expanded.
        • 
        
      • Each module is expanded once, at its shallowest depth.
        • 
      
      
      
      Needs Service Studio free: it will not start while a rebuild is reading. Starting is only allowed from this PC; other devices can watch.
